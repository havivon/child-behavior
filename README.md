# רגוע וחזק

אפליקציית ווב בקובץ אחד (`index.html`) ללוות הורים בתוכנית בת 12 שבועות: סדר יום, כלי רגיעה לילד, רישום אירועים, גרפי התקדמות ומדריך להורה.

- כל הנתונים נשמרים בטלפון בלבד (localStorage). בהגדרות (⚙️) יש ייצוא/ייבוא גיבוי JSON.
- `sw.js` הוא קובץ אופציונלי: כשהאפליקציה מתארחת ב-https (למשל GitHub Pages) הוא מאפשר לפתוח אותה ממסך הבית גם בלי אינטרנט. בלעדיו הכל עובד כרגיל.

## פתיחה בטלפון

**הדרך המומלצת – GitHub Pages:**
1. ב-GitHub: Settings → Pages → Source: *Deploy from a branch* → בוחרים את הענף ואת התיקייה `/ (root)` → Save.
2. אחרי דקה-שתיים מתקבלת כתובת בסגנון `https://<user>.github.io/child-behavior/`.
3. פותחים את הכתובת בטלפון:
   - **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
   - **אנדרואיד (Chrome):** תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה".

**בלי אינטרנט/אירוח:** שולחים לעצמכם את הקובץ `index.html` (מייל, וואטסאפ, Drive), שומרים אותו בטלפון ופותחים אותו בדפדפן. הנתונים יישמרו בדפדפן שבו פתחתם.
