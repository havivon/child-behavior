# רגוע וחזק

אפליקציה בעברית שמלווה הורים בתוכנית בת 12 שבועות: סדר יום, כלי רגיעה לילד, רישום אירועים, גרפי התקדמות ומדריך להורה.

## קבצים להורדה (`dist/`)
| קובץ | מה זה |
|---|---|
| `ragua-vehazak.apk` | אפליקציית אנדרואיד (אנדרואיד 5 ומעלה) |
| `ragua-vehazak.html` | אותה אפליקציה כקובץ HTML יחיד, עובד בכל דפדפן גם בלי אינטרנט |

## התקנה באנדרואיד
1. מעבירים את `ragua-vehazak.apk` לטלפון (וואטסאפ לעצמכם, מייל או Google Drive) ופותחים אותו.
2. אם מופיעה בקשה, מאשרים "התקנה ממקורות לא ידועים" לאפליקציה שממנה פתחתם את הקובץ.
3. לוחצים "התקנה". ייתכן ש-Google Play Protect ישאל על אפליקציה לא מוכרת. זה צפוי לאפליקציה שלא הגיעה מהחנות: בוחרים "התקנה בכל זאת".

## שימוש בקובץ ה-HTML
פותחים את `ragua-vehazak.html` בדפדפן בטלפון או במחשב. באייפון אפשר להוסיף אותו למסך הבית דרך Safari (שיתוף ← "הוספה למסך הבית"); זה עובד הכי טוב כשהקובץ מתארח בכתובת https, למשל ב-GitHub Pages.

## חשוב לדעת
- הנתונים נשמרים רק במכשיר. כדאי לייצא גיבוי מדי פעם (⚙️ הגדרות ← ייצוא).
- הסרת האפליקציה מוחקת את הנתונים, ולכן מייצאים גיבוי לפני הסרה.
- אפליקציה ודפדפן הם מקומות נפרדים: מעבירים נתונים ביניהם דרך ייצוא וייבוא.

## למפתחים
- `index.html` הוא קוד המקור, כקובץ יחיד. `sw.js` הוא קובץ אופציונלי למטמון אופליין כשהאפליקציה מתארחת ב-https.
- בדיקות: `node tests/e2e.js`. 129 בדיקות Playwright; ראו `tests/README.md`.
- בניית ה-APK: `./android/build.sh`; ראו `android/README.md`. מפתח החתימה נמצא ב-`android/keystore/` בכוונה: בלעדיו אי אפשר להתקין עדכון מעל הגרסה הקיימת בלי למחוק את הנתונים.
- תיעוד הצוות: `docs/spec.md` (המפרט), `docs/design-review.md` (סקירת העיצוב), `docs/qa-report.md` (3 סבבי QA).
