# אייקון – 3 הצעות

השוואה: `compare.png`. כל תיקייה מכילה `icon.svg` (מלא, 512×512), `icon-foreground.svg` ו-`icon-background.svg` – אותו מבנה כמו `docs/design`, כדי שאפשר יהיה להחליף.

1. **נשימת בלון** (`option-1`)
   בלון לבן שמתמלא אוויר, עם גלי נשימה רכים משני צדדיו, על רקע הטורקיז-כחול של האפליקציה.
   מזכיר את כלי הרגיעה המרכזי – נשימת הבלון – ומשדר שקט, קלילות ונשימה עמוקה.

2. **עץ מגן** (`option-2`)
   עץ חסון עם גזע ושורשים יציבים וצמרת רחבה ועגולה, על רקע ירוק-טורקיז.
   העץ שומר ומגן כמו הורה רגוע, ומבטא את ה"חזק" שבשם: יציבות, צמיחה ומחסה למשפחה.

3. **מהסערה לשקט** (`option-3`)
   שלושה גלים: אדום סוער למעלה, כתום שמתרכך, וירוק-טורקיז רגוע למטה, על רקע שמנת חם.
   זה מדחום הרגשות בתנועה – מהכעס אל הרוגע – והצבעים החמים מבליטים אותו על מסך הבית.
